# Kopi Saigon Badges & Iconography

These official icon assets denote drink specialties and temperature availability across Kopi Saigon menu cards.

## Available Assets

### 1. `fav-star.png` (Signature Gold Star Badge)
- **Role:** Denotes **Bestseller / Crowd Favorite** items (e.g. Kopi Saigon, Kopi Latte, Kopi Buttercream, Matcha Original, Peach Tea, Creamy Taro, Strawberry Milkshake).
- **Placement:** Top-left corner of the product tile (`position: absolute; top: 14px; left: 14px; width: 28px; height: 28px;`).

### 2. `badge-hot-cold.png` (Dual Temperature Indicator)
- **Role:** Indicates the beverage can be ordered **Hot or Iced (Cold)**.
- **Placement:** Bottom-center or bottom-right of the product card (`width: 54px; height: auto;`).

### 3. `badge-cold-only.png` (Cold-Only Indicator)
- **Role:** Indicates the beverage is served **Cold / Iced only** (e.g. all Frappes, Fruit Teas, Flavored Cold Matchas).
- **Placement:** Bottom-center or bottom-right of the product card (`width: 54px; height: auto;`).
