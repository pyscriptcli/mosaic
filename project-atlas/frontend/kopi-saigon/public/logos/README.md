# Kopi Saigon Official Logos

Vector SVG logos of the official Kopi Saigon emblem: the Vietnamese conical hat (*nón lá*) coffee artisan inside an arched portal crest.

## File Manifest

| File | Color | Best Used On |
|---|---|---|
| `logo.svg` / `logo-brown.svg` | `#783819` (Saigon Roast Brown) | Light/Cream backgrounds (`#F3E8D7`, `#FFFFFF`, `#FAF5EE`) and Golden Amber headers (`#E6B549`). |
| `logo-white.svg` | `#FFFFFF` (Pure White) | Dark surfaces, solid brown hero banners (`#783819`), dark photo overlays. |
| `logo-cream.svg` | `#F3E8D7` (Condensed Milk Cream) | Soft contrast on deep brown backgrounds. |
| `logo-gold.svg` | `#E6B549` (Warm Golden Amber) | Premium merchandise, dark packaging, luxury accents. |

## Sizing & Clear Space
- **Minimum Digital Display Height:** `40px` (ensures the delicate coffee drip & hat line art remains legible).
- **Clear Space:** Maintain margin of at least 20% of the emblem's height on all four sides.
- **Never distort or stretch:** Always preserve aspect ratio `202.53 : 240.19` (approx `0.84 : 1`).
